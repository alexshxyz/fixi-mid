# fixi-mid — обзор проекта

`fixi-mid` — Python-бот для мониторинга футбольных матчей в Live-таблице Goaloo. Он собирает счёт, игровое время и коэффициенты, ищет изменения линий over и азиатской форы (AH), отправляет сигналы в Telegram и позже обновляет их статус.

## Как проходит обработка

1. `app/main.py` проверяет настройки, запускает Playwright, открывает Goaloo и переключает страницу на Live. В мониторинг попадают активные матчи с доступными данными коэффициентов.
2. `app/observer.py` извлекает данные матчей и отслеживает изменения Live-таблицы. `app/tracker.py` хранит историю снимков, обновляет матчи и запускает анализ при новых данных.
3. `app/closed_ov_ah.py` ищет закрытие линии после подходящего изменения коэффициента. Условия задаются `START_ODD` и `THRESHOLD` в `app/config.py`; завершённые матчи и несовпадающий известный счёт исключаются.
4. `app/notifier.py` проверяет дубликаты по матчу и рынку, отправляет сигнал через Telegram Bot API и сохраняет запись в `app/storage.py`.
5. После успешной отправки `app/pending_notifications.py` планирует проверку примерно через три минуты. Статус сообщения обновляется с учётом закрытия рынка и списка лиг; неудачные попытки повторяются с ограничением.

При `SIGINT` или `SIGTERM` приложение останавливает работу, закрывает браузер и сохраняет состояние мониторинга. Перезапуск также выполняется при ошибках браузера и по плановому интервалу.

## Основные модули

| Файл | Назначение |
| --- | --- |
| `app/main.py` | Точка входа: настройка браузера и страницы, сбор матчей, управление перезапуском и завершением. |
| `app/config.py` | Настройки окружения, таймауты, пороги сигналов, пути к данным и список лиг. |
| `app/scripts.py` | JavaScript-код для извлечения данных и отслеживания изменений DOM. |
| `app/observer.py` | Чтение Live-таблицы, ожидание изменений и обновление страницы. |
| `app/tracker.py` | История матчей, цикл мониторинга, сохранение и восстановление состояния. |
| `app/closed_ov_ah.py` | Поиск сигналов для рынков over и AH. |
| `app/notifier.py` | Формирование, отправка и сохранение Telegram-уведомлений. |
| `app/pending_notifications.py` | Отложенное обновление статуса отправленных сообщений. |
| `app/storage.py` | Хранение уведомлений и результатов в JSON, проверка дубликатов и обновление отметок. |
| `app/state.py` | Сохранение и восстановление состояния мониторинга. |
| `app/logger.py` | Настройка логирования приложения и утилит. |

## Конфигурация и данные

- `.env` хранит секреты и настройки окружения, включая `BOT_TOKEN`, `CHANNEL_ID` и обязательный `BROWSER_PROXY_SERVER`. Не добавляйте его в Git.
- `BROWSER_PROXY_SERVER` задаёт прокси браузера; Telegram-прокси настраивается отдельно через `TELEGRAM_PROXY_HOST` и `TELEGRAM_PROXY_PORT` (при необходимости — логин и пароль).
- `data/matches.json` — хранилище уведомлений; путь можно изменить через `MATCHES_FILE`. `app/tools/export.py` создаёт CSV рядом с этим JSON-файлом.
- `data/leagues.json` содержит список лиг для выбора отметки уведомления.
- `data/match_state.json` временно хранит состояние, чтобы продолжить мониторинг после перезапуска; после успешного восстановления файл удаляется.
- При `DEBUGMODE = 1` создаются диагностические `data/count.json` и `data/data_closed_ov_ah.json`.
- `bot.log` содержит лог основного приложения, `monitor.log` — лог утилиты мониторинга.

## Утилиты и тесты

- `app/tools/export.py` экспортирует сохранённые матчи в CSV.
- `app/tools/stats_manual.py` содержит функции расчёта и форматирования статистики.
- `app/tools/monitor.py` проверяет свежесть `bot.log` и отправляет статус в Telegram.
- `tests/` содержит pytest-тесты. Тесты с меткой `smoke`, которым нужны браузер или внешние сервисы, по умолчанию исключены.

## Запуск

Запустите `python -m app.main`. Нужны зависимости из `requirements.txt`, доступ к Goaloo и корректные настройки Telegram и прокси браузера. Настройки разработки и тестирования перечислены в `requirements-dev.txt`.
